STEP 2 多引擎策略配置Multi-engine strategy configuration

在 pFind / pUniFind 生态（b–e）之外添加搜库和从头测序引擎软件，参与竞争仲裁。
Add search and de novo sequencing engines beyond the pFind / pUniFind ecosystem (b–e).

⚙ 当前策略槽位Active strategy slots

a ＝ 步骤 1 输入的原始搜库结果（不一定是 pFind）；b/c/q ＝ pFind 三臂（开放式/限定式多参数/常规限定式）；d/e ＝ pUniFind 矫正/从头测序；f–p ＝ 其他搜库和从头测序引擎（下方添加）
a = the original search result from step 1 (any engine); b/c/q = the pFind arms (open / restricted multi-mod / standard closed); d/e = pUniFind re-score / de novo; f–p = other search & de novo engines (add below)

+ 搜库和从头测序引擎Search and de novo sequencing engines

+ 策略槽位（pFind 三臂与 pUniFind 同样在这里添加）Strategy slots (the pFind arms and pUniFind are added here too)

pFind 三臂＝b 开放式 / c 限定式多参数 / q 常规限定式：Auto＝填 pFind 安装目录自动搜库，Manual＝填既有结果文件/文件夹。pUniFind＝d 开放式矫正（输入为 open 结果；Auto 需 punifind 目录＋下方 Python 字段）/ e 从头测序。与其他引擎行完全同构，任意组合。
pFind arms = b open / c restricted multi-mod / q standard closed: Auto fills the pFind install folder and searches; Manual takes an existing result file/folder. pUniFind = d open-search re-score (input = open results; Auto needs the punifind folder + the Python field below) / e de novo. Same row mechanics as every other engine - combine freely.

⚠ 已有 pUniFind 矫正（d）行，但没有 pFind open（b）行——矫正的输入是开放式搜库结果：请添加 open 行（Auto 或 Manual 均可），否则运行时矫正将被跳过。
A pUniFind re-score (d) row is present without a pFind open (b) row - re-scoring consumes open-search results: add an open row (Auto or Manual), otherwise re-scoring is skipped at runtime.

每行可选 Auto search（自动搜库：填软件路径；MaxQuant 另需 raw 输入，其余引擎自动用第一步 MGF）或 Manual search（手动结果：填结果文件/文件夹）。配置完成后请到"参数汇总"页统一生成。Each row picks Auto search (fill the software path; MaxQuant additionally needs raw input, other engines reuse the step-1 MGF) or Manual search (fill the result file/folder). After configuring, go to the Summary page to generate.

Result paths accept a file or folder (folders auto-resolve by engine type, newest wins). Adapters handle format conversion, modification-name mapping and scan-number alignment.

STEP 3 理论谱图预测器Theoretical spectrum predictors

阶段 A 的「预测余弦」一票可由多个理论谱图预测软件产生（pDeep2、MS2PIP 等，均为用户自装的独立软件）：在下方各行配置每个软件的路径与开关，再选择主预测器；不需要的软件可整行移除。主预测器选「不进行理论谱图预测」即关闭预测（自动把 use_pdeep2 置 0，predict 列按缺失处理）。
The stage-A predict vote can come from multiple predictor software (pDeep2, MS2PIP and the like - all separate software installed by the user): set each software's path and switch in the rows below, then pick the primary; rows not needed can be removed. Selecting "no theoretical prediction" turns prediction off (use_pdeep2 is set to 0 and the predict column is treated as missing).

配置完成后请到"参数汇总"页统一写入。After configuring, go to the Summary page to write.

适配器位于 code/predictors/pred_<type>.R（随软件分发 ms2pip 适配器，预测软件本身需用户安装）；每个预测器产物 merge/predict_<type>.txt 与 pDeep2 predict.txt 同构；运行失败只记 merge/predictor_run_manifest.txt、该列按缺失处理，不打断整轮。
Adapters live in code/predictors/pred_<type>.R (the ms2pip adapter ships with the software; the predictor software itself must be installed by the user); each predictor writes merge/predict_<type>.txt shaped like pDeep2's predict.txt; failures only mark merge/predictor_run_manifest.txt and the column is treated as missing.
